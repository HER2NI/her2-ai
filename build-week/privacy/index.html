H.E.R Privacy

Scope

This notice covers the public her2.ai website and the private, pre-launch H.E.R Build Week prototype.

Public website

The public website does not intentionally include advertising trackers or analytics cookies in its page code. The hosting and security provider may process ordinary network metadata, including IP address, request time, requested path, browser information, and security signals, to deliver and protect the site.

Prototype model processing

When a user submits an instruction through the H.E.R synthesis prototype, the instruction and permitted request context are sent to HER2NI-operated relay infrastructure and then to the selected artificial intelligence provider routes required for that turn.

H.E.R may use multiple independent provider routes and one synthesis route. The provider routes process the material supplied to them under their applicable service terms and data-handling settings.

Structural records

The current iPhone prototype may generate a local Trace, Receipt commitment, Drop commitment, and local Structural Proof manifest. These records describe bounded execution structure. They do not certify factual truth or answer correctness.

In the current Build Week boundary, Proof network sync, public Proof export, signatures, and public Relay verification are not activated unless expressly stated in the interface and testing instructions.

Memory

The demonstrated mode uses chat-scoped continuity. Durable portable H.E.R-ID memory is not activated merely because a user accesses the prototype.

Operational evidence

Sanitized screenshots, route status, model identifiers, request identifiers, timestamps, test results, and bounded diagnostic records may be retained to document Build Week performance and reliability. Secrets and private user content should not be included in public evidence.

Do not submit sensitive information

The Build Week prototype is not intended for confidential legal, medical, financial, employment, national-security, authentication, or other highly sensitive information.

Requests and contact

For a privacy request concerning information controlled by HER2NI, contact research@her2ni.ai.
